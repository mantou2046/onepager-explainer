# qa-gates.md —— 质量门禁（每道工序的验收）

> 原则：**每道工序有可执行验收，不靠「我觉得」**；不确定的环节（TTS）可插拔 + 有降级。
> 门禁分四层，前三层默认流程必过，第四层仅在用户要语音时执行。
> ⚠️ 2026-10-15：第 2 层补「**美感基线 / 教学法四条 / 公式精度**」三组勾选（源自库内笔记的 10-14 沉淀与 10-15 晚四方评审定版，规范正文见 `design-tokens.md`）。

## 第 1 层 · 素材关

- [ ] 来源是官方文档/一手资料；用户指定的来源不外延、不补私货
- [ ] 抓取：WebFetch 空返 → 换 `curl -sL --noproxy '*'`；SPA 站（Docusaurus 等）正则抠正文
- [ ] **口径核实**：`/zh` 页面 lang=zh 但正文可能是英文（官方翻译未完成）——抓完必须核对正文语言，页面底部如实注明（Helm 页的教训）
- [ ] 页面含「翻译/版本状态」注明的，如实转写，不美化

- [ ] **打印实测过**（不许只读代码判过）：用无头 Chrome `--print-to-pdf` 在「深色主题 + 宽表横滚在最左 + 讲解器停在第 1 步 + 折叠区未打开 + 筛选不在全部」状态下真打一份 PDF，用 pdftotext 抽字断言四处哨兵都在——宽表最右列列名、宽表末行末格、讲解器最后一步标题、折叠区内关键词；缺一即打印基线不过。另查 `@page` 在位、横滚容器打印段已解除、长表跨页有重复表头。**本步已封装为脚本，跑 `python scripts/print_check.py <页面.html>` 退出码 0 即可**（静态审计 12 项 + 深/浅各打一份 PDF；脚本按页面内容自动抽最多五类哨兵——宽表最右列列名、宽表末行末格、讲解器末步正文、讲解器附加字段、折叠区正文，缺一即不过。后三类中，末行末格防表头字样在别处复现导致假通过，附加字段防「此刻演示里」「以为/其实」这类独立段落整块丢失）。⚠️ 只读代码判「打印没问题」一律不算过——2026-10-30 实测 8 个存量成品，`@page` / `overflow:visible` / `min-width:0` 全为 0，4 个带折叠区的页面折叠正文在 PDF 里全缺。

> [!warning] **哨兵比对的三个坑（2026-10-30 全量 24 页实测后修，改 `print_check.py` 前必读）**
> 断言是「抽出的字里能不能找到这串」，但 PDF 抽字有两个与内容无关的失真源，处理不好会把「印在纸上」误判成「丢了」：
> 1. **PDF 文本不能当 HTML 剥标签**。正文里天然含 `<`（`<1.15.0`、`helm show chart <chart>`），用 `TAG_RE = <[^>]+>` 去删会把 `<` 到下一个 `>` 之间整段吞掉——实测 Helm 页被删 4433 字（正好是哨兵所在的命令速查表），8674 字只剩 4874，判定必失败。所以源码侧用 `norm()`（剥标签），PDF 侧用 `norm_pdf()`（**只反转义 + 抹空白**）。
> 2. **折行的单元格会被邻列插断**。pdftotext 默认按视觉行输出：一格折成两行时，第二行开头会被左侧邻列挤到中间。实测 vLLM 页抽出来是「分机号要转接到对的 ｜ 写错全链路不通 ｜ 工位」，源码里却是「分机号要转接到对的工位」+「写错全链路不通」两格。`-layout` 模式一样交错。解法是拿 `-bbox-layout` 的词坐标重建「栏」文本（`column_text`：以 xMin 锚定、逐行向右扩张；`band_text`：以整行连续片段为列带），命中任一份即算印出。**这两个视图只收集 PDF 里实际存在的词，内容真丢时照样判失败**——已用「打印时 `table tr:last-child{display:none}`」反向验证过退出码仍为 1。
> 3. **同一视觉行的词 y 有 0.2~0.4 抖动**，`round(y,1)` 排序会把行内顺序打乱（实测「处」y=207.9 排在「secret」y=207.7 之后 → 拼成「几 secret 处要对齐」）。必须按 y 容差（2pt）聚行再按 x 排。
> 4. **「讲解器末步」哨兵必须认全部步骤数组名**（2026-10-30 补）：`QSTEPS / STEPS / STEPS_DATA / STEP_DATA / ST / steps` 六种，且正文键有 `say / body / b / d / desc`，还有整步用 `do/done/plan` 并列字段的、正文是字符串数组的。只认 `QSTEPS` + `say` 会让 `const ST` 这类页面整段丢内容还判「通过」——实测 4 页（Langfuse / vLLM / K8s 生产化四件套 / FastAPI 流式响应）7 步里只印出第 1 步，门禁全绿。

## 可选步骤 · AI 同类产物评审

用户拿来 AI 生成的同类页面时，逐项对比：**借有价值的点（每点落到页面），明确拒绝不合适的点并记原因**（Helm 页经验：借 8 点、拒 3 点，收益极高）。拒绝的理由写进交付说明，避免下次又捡回来。

## 降级链（第④屏讲解器，embed_后自动生效）

内嵌音频（Web Audio）→ 解码失败/AudioContext 缺失 → speechSynthesis（rate 0.95）→ 全无 → 4.5s/步纯计时。
每级带安全计时（音频 QDUR+8s / TTS ×1.3+6s）。首载不发声（等用户手势）。
